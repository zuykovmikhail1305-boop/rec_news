# rec_news

Новостная аналитика: сбор публикаций, обработка и персональные инсайты для компаний.

**Общая архитектура с Mermaid-схемами:** [docs/architecture.md](docs/architecture.md).
Документ описывает сервисы, общую БД, очереди, поток новостей и карточек,
а также проектные механизмы безопасности AI-компонентов.

## Сервисы

- [Backend](services/backend/README.md) — веб-интерфейс и запуск обработки новых
  новостей через ML API. Порт `8000`.
- [Parser](services/parser/README.md) — RSS, извлечение полного текста, очередь
  сбора и запись входных новостей ML. Порт API `8001`.
- [ML](services/ml/README.md) — обработка, дедупликация, аналитика,
  персональные ленты и генерация карточек. Порт API `8002`.

Сервисы запускаются независимо из своих каталогов со своими зависимостями.
Основной локальный запуск — через `uv`; PostgreSQL, RabbitMQ и Qdrant можно
запускать в Docker. Команды и переменные окружения приведены в README сервисов.

## Данные

Рабочая интеграция использует общую PostgreSQL-базу: parser сохраняет
`public.news_raw` и передаёт публикации в `ml_news.news`. Backend обнаруживает
новые строки и вызывает processing в ML. Для разработки остаются локальные
режимы SQLite; данные из них автоматически в PostgreSQL не переносятся.

[Контракт новостей](docs/news-schema.md).
`app/` содержит прежние реализации; актуальные сервисы находятся в `services/`.
Демо-интерфейс работает без авторизации; проектные меры разграничения доступа
и защиты AI-инструментов описаны отдельно в архитектурном документе.
