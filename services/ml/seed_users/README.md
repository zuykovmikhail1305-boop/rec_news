# Пользователи для базы ML

Всё, что нужно, чтобы загрузить пользователей демо в базу (PostgreSQL или SQLite из `.env`).

| Файл | Что внутри |
|---|---|
| `load_users.py` | скрипт загрузки и выгрузки |
| `users.json` | анкеты пользователей (`UserProfileIn`): роль, компания, `company_id` из датасета |
| `profiles.jsonl.gz` | готовые профили интересов к анкетам: загрузка без LLM за секунды |

Сейчас в папке 12 пользователей: 9 профилей демо-входа «роль + компания» (`demo_<роль>_<компания>`,
см. `services/backend/backend/demo.py`) и 3 исходных профиля компаний `u_01`, `u_02`, `u_07`.

## Загрузка

Из папки `services/ml`, база должна быть запущена (`docker compose up -d`):

```bash
uv run --env-file .env seed_users/load_users.py
```

* уже загруженные с той же анкетой пропускаются — повторный запуск безопасен;
* `--force` — перезаписать; `demo_cfo_build u_02` — загрузить только этих;
* `--no-build` — только готовые профили, без LLM.

## Свои пользователи

Добавьте анкету в `users.json` (обязательны `user_id` и `role`; с `company_id` профиль дополняется данными
датасета) и запустите загрузку: профиля к новой анкете в `profiles.jsonl.gz` нет, поэтому он построится через
LLM и датасет компаний. Чтобы сохранить построенные профили в папку для следующих запусков:

```bash
uv run --env-file .env seed_users/load_users.py --export
```

`--export` без аргументов выгружает всех пользователей базы, с аргументами — только указанных.
