# Демонстрация парсера

Сценарий для встречи **22 октября 2026, 13:00 (+03:00)**.

## Открыть без установки

Скачайте **parser-demo.html** из этой папки и откройте двойным щелчком в современном браузере. Python, сервер, интернет, ключи и база данных не нужны. CSS и JavaScript встроены; внешних шрифтов нет. Открытие страницы в режиме предпросмотра репозитория не запускает JavaScript — нужен именно скачанный HTML.

**Все данные и суммы синтетические.** Условные 500 ₽ — не согласованный бюджет, 18/53/26 ₽ — не тарифы и не оценка стоимости обработки. Реальные цены и точные версии моделей неизвестны; утверждения, что одна из них дешевле других, не делаются. Названия источников и моделей показывают предполагаемые роли, а не работающие интеграции.

## Показ за 3–5 минут

1. Обозначить границы: это интерактивная имитация архитектуры, не работающий парсер. Нет RSS/HTML-запросов, LLM-вызовов или записей в БД. Внешние сервисы не подключены.
2. Оставить шесть источников, выбрать интервал 15 или 60 минут. Пояснение под настройкой меняется: это будущая настройка планировщика, **автоопроса нет**, кнопка моделирует один цикл. Изменение настройки очищает предыдущий результат.
3. Выбрать «Обычный» и нажать «Запустить прогон»: 6 → 42 raw → 35 уникальных → 8 релевантных → 8 обогащённых → 3 инсайта. Условные расходы 97 ₽. Результаты детерминированы и не являются прогнозом объёмов или качества моделей.
4. Открыть «Показать детали»: журнал только завершённых шагов, пример source → raw → relevance → enrichment → insight. Можно открыть журнал во время прогона. Выбранный первый источник определяет подпись примера.
5. Выбрать «Лимит исчерпан» и повторить. Начальный условный расход 500/500 ₽. Сбор и дедупликация завершаются, **42 raw сохранены**, **35 кандидатов отложено**, все три LLM-шага пропущены. Новых расходов нет, готовых инсайтов нет. Журнал не выдаёт пропущенные шаги за выполненные.
6. Снять все галочки: запуск просит выбрать источник, данные не создаются. Оставить один: 7 raw, 5 уникальных, 3 релевантных/обогащённых, 1 инсайт. Это специально заданная демонстрационная формула; расходы этапов также фиксированные условные, не расчёт по токенам.
7. Нажать «Сбросить» во время прогона и сразу запустить снова. Старые таймеры не вмешиваются. Повторный прогон начинает чистый цикл, не накапливает суммы или raw. Настройки сохраняются; журнал закрывается. Во время прогона настройки заблокированы, сброс доступен.

Raw существует **только в памяти страницы** до сброса, нового прогона, смены настроек или закрытия. Долговременное хранение, возобновление отложенной очереди, реальная дедупликация и планировщик не реализованы. В архитектуре эти обязанности относятся к воркеру и БД; FastAPI отображает интерфейс.

## Запуск через FastAPI

Из корня репозитория (Python 3.12, зависимости проекта):

```sh
cd app
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
DATABASE_URL=sqlite:////tmp/parser-demo-local.sqlite .venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
```

Открыть `http://127.0.0.1:8000/insights/parser`. Если `.venv` уже подготовлена, достаточно последней команды. Установка зависимостей требует сети; само демо — нет. Сервер создаёт таблицы в отдельной SQLite-базе из команды, но демо в неё ничего не записывает. `Ctrl+C` останавливает сервер.

## Пересобрать автономный файл

Источники: `app/templates/insights/parser.html`, `app/static/parser.js`, `app/static/parser.css`, общий `app/static/insights.css`.

```sh
python3 scripts/build-parser-demo.py
```

Только стандартная библиотека Python; результат `docs/parser-demo.html`. Навигация к серверному прототипу заменяется текстом. Сгенерированный HTML коммитится вместе с изменениями исходников.

## Проверки браузером

Нужны уже установленные Node.js, Playwright и Chromium (скрипт сам ничего не скачивает):

```sh
node --check app/static/parser.js
node tests/parser-demo.cjs
# Если Playwright установлен вне проекта:
PLAYWRIGHT_MODULE=/absolute/path/to/playwright node tests/parser-demo.cjs
# Для уже запущенного локального FastAPI:
DEMO_URL=http://127.0.0.1:8000/insights/parser node tests/parser-demo.cjs
```

Тест запускает headless Chromium, запрещает внешние HTTP(S)-запросы и проверяет: 6 чекбоксов; изменение условного интервала; пустой выбор; обычный прогон и все счётчики; открытие/закрытие трассировки; повтор без накопления; исчерпанный бюджет без LLM, с raw и отложенными; один выбранный источник; сброс на ходу и немедленный replay без вмешательства старых таймеров; отсутствие JS-ошибок и внешних запросов. В sandbox-контейнере тест использует `--no-sandbox`: запускать только для этого доверенного локального демо.
